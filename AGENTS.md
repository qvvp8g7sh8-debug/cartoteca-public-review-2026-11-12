# Инструкции для анализа этой копии

Это публичный снимок Картотеки для независимого анализа. Начните с README.md, package.json и соответствующих файлов src/ и tests/.

- По умолчанию только анализируйте код и сообщайте подтверждённые замечания с путями и строками.
- Не запускайте публикацию, миграции, резервирование, release-команды и подключения к реальным серверам или внешним провайдерам.
- Если владелец отдельно попросит тестирование, используйте только временную синтетику в изолированной среде.
- Не запрашивайте и не добавляйте реальные секреты, данные клиентов, ключи или фотографии.
- Внутренние журналы, серверные настройки и часть документации намеренно исключены. Отсутствие этих материалов само по себе не является ошибкой приложения.
