# Связи клиентских модулей

Создаётся проверкой архитектуры. `state` — состояние одного приложения; `actions` — ограниченные read-only порты из manifest.dependencies. Общий реестр доступен только композиции. Проверяются имена, явные зависимости и арность; строгие типы команд сохранения — contracts/domain.d.ts. Для изменения функции найди строку, не читай весь граф.
