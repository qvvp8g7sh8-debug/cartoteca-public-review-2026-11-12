POST /api/max/webhook — единственное provider-исключение browser-CSRF: Host проверяется, секрет MAX проверяется до чтения тела, затем предел 32 КБ и фиксация шифрованного inbox до HTTP 200. По умолчанию обработчик выключен. Остальные public-маршруты сохраняют browser-CSRF.

Public означает отсутствие обязательной сессии, но не отсутствие проверки токена, пароля и ограничения запросов. Публичная онлайн-запись работает только после включения владельцем/администратором; бюджет, подпись формы и доступность проверяются на сервере.
